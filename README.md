# Dot Files

- Install "ohmyzsh" [here](https://ohmyz.sh/)
- Copy [home_files/.zshrc](./home_files/.zshrc) to `~/.zshrc` (or run `./install.sh`, which backs up your existing dotfiles to `~/.dotfiles_backup/` first)
- Reload the shell using `source ~/.zshrc`
